# Учебный проект "Виджет банковских операций клиента"

## Описание:

Данный проект представляет собой виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

- Клонируйте репозиторий:
```
git clone https://github.com/Oleg-Krasikov/BankProject.git
```
- Установите зависимости:
```
poetry lock
poetry install
```

## Функции:

1. ```get_mask_card_number``` - маскирует номер карты, оставляя первые 6 и последние 4 цифры, остальные заменяет на '*'.

2. ```get_mask_account``` - маскирует номер счёта, оставляя только последние 4 цифры.

3. ```mask_account_card``` - маскирует номер карты или счета в переданной строке.

4. ```get_date``` - преобразует строку с датой в формате ISO ("2024-03-11T02:26:18.671407")
    в строку формата "ДД.ММ.ГГГГ" ("11.03.2024").

5. ```filter_by_state``` - фильтрует список транзакций по указанному статусу.

6. ```sort_by_date``` - сортирует список словарей по дате в указанном порядке.

7. ```filter_by_currency(transactions, currency)``` - фильтрует транзакции по заданной валюте.

8. ```transaction_descriptions(transactions)``` - генератор описаний транзакций.

9. ```card_number_generator(start, end)``` - генератор номеров банковских карт

# Тестовая документация

## Модульные тесты

Проект включает комплексные модульные тесты, охватывающие основные функции:

### Маскировка карт и счетов

Тесты проверяют корректность маскировки конфиденциальной информации:
- Действительные и недействительные номера карт
- Действительные и недействительные номера счетов
- Обработка крайних случаев
```
@pytest.mark.parametrize(
    "account_info, expected",
    [
        ("Счет 1234567890123456", "Счет **3456"),
        ("Visa Platinum 9999888877776666", "Visa Platinum 9999 88**** 6666")
    ]
)
def test_mask_account_card(account_info, expected):
    assert mask_account_card(account_info) == expected
```

### Форматирование даты

Тесты проверяют преобразование даты из формата ISO в ДД.ММ.ГГГГ:
- Корректные строки даты
- Обработка некорректных форматов
- Крайние случаи
```
def test_get_date_valid():
    assert get_date("2024-03-11T02:26:18.671407") == "11.03.2024"

def test_get_date_invalid():
    with pytest.raises(ValueError):
        get_date("invalid-date")
```

### Обработка транзакций

Тесты охватывают фильтрацию и сортировку транзакций:
- Фильтрация по состоянию
- Сортировка по дате
- Крайние случаи
```
def test_filter_by_state():
    transactions = [
        {"state": "EXECUTED", "date": "2019-07-03"},
        {"state": "CANCELED", "date": "2018-06-30"}
    ]
    result = filter_by_state(transactions, "EXECUTED")
    assert len(result) == 1
```

### Фильтрация транзакций
- Проверка фильтрации по разным валютам
- Обработка пустого списка
- Обработка некорректных данных

### Генератор описаний
- Нормальные транзакции
- Пустые списки
- Большие объемы данных
- Обработка ошибок (отсутствующие поля)

### Генератор номеров карт
- Корректные диапазоны:
  - Малые диапазоны
  - Верхние границы значений
- Формат вывода:
  - Проверка длины строки (19 символов)
  - Корректность разделения пробелами
- Обработка невалидных диапазонов:
  - Отрицательные числа
  - Старт больше конца
  - Переполнение максимального значения

## Тестовые фикстуры

В тестовом наборе используются фикстуры pytest для тестовых данных:
```
@pytest.fixture
def sample_transactions():
    return [
        {"id": 1, "state": "EXECUTED", "date": "2019+07+03"},
        {"id": 2, "state": "CANCELED", "date": "2018-06-30"}
    ]
```

## Выполнение тестов

Чтобы выполнить все тесты:
```
poetry run pytest
```
